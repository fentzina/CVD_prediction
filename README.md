# CVD_prediction

## Machine Learning Pipeline for Feature Selection and Predictive Modeling 
Building on the CVD descriptive analysis, I implement a machine learning (ML) pipeline to identify the most informative features in my dataset and build a predictive model. The goal is to understand which variables contribute most to the clinical outcome of interest and evaluate the performance of a predictive model. 
## Tasks: 
1. Feature Selection: 
Apply feature selection techniques to reduce dimensionality and identify the most 
informative variables. 
2. Model Building: 
Select an appropriate predictive model based on your dataset and clinical problem. 

### Implement a ML pipeline that includes: 
o Data preprocessing (scaling, encoding categorical variables if needed) 
o Feature selection 
o Model training 
o Model evaluation

### Methodology 
• Preprocessing and feature selection steps. 
• Model selection. 
• Pipeline structure and evaluation strategy (cross-validation, metrics). 

### Results
